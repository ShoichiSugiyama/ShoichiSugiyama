# はじめまして

会計顧問・損害保険代理店・IT/AI支援の3つの領域で、日々の実務に取り組んでいます。

数字のこと、保険のこと、業務で使うITのこと。それぞれを別々に考えるだけでなく、仕事全体の流れを見ながら、困りごとを一緒に整理することを大切にしています。

## 取り組んでいること

| 領域 | 主な取り組み |
| --- | --- |
| 会計顧問 | 日々の会計実務を支え、数字を把握しやすい形に整理すること |
| 損害保険代理店 | 事業や業務の状況を踏まえた保険の相談対応。補償の対象・対象外・条件をわかりやすく伝えること |
| IT/AI支援 | 業務に合ったITの導入支援と、AIを実務で使うための活用支援 |

IT/AI分野では、ClaudeやNotebookLMを使った研修づくりにも取り組んでいます。日々の仕事で無理なく使い続けられる形を考えています。

## 大切にしていること

- まず状況を伺い、何に困っているのかを一緒に整理する
- 専門用語に頼りすぎず、条件や注意点も含めて説明する
- 導入や契約を急がせず、必要なことから順に考える
- わからないことは確認し、最後まで丁寧に対応する

「何から聞けばよいかわからない」という段階でも、相談しやすい存在でありたいと思っています。
